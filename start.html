신규 등록 대상 기기에는 60분 체험 시간이 제공됩니다. 기존에 사용한 기기는 PC의 잔여 시간을 먼저 확인해 주세요.

02

기록을 보관할 호스트 PC를 실행하세요.

휴대폰과 다른 상담원 PC가 연결될 기준 PC입니다.

홈 → 서버 탭을 여세요.

왼쪽 메뉴에서 홈을 누르고 상단의 서버 탭을 선택합니다. 오른쪽 위 사용자정보에 ‘상담팀’처럼 사용할 이름을 입력하세요.

비밀번호와 원격주소를 확인하세요.

비밀번호는 6글자 이상으로 설정합니다. 화면에 표시된 원격주소는 휴대폰을 연결할 때 사용합니다.

필요한 경우 녹음 저장 폴더를 정하세요.

PC의 ‘녹음파일’ 항목은 PC에 기록을 저장할 위치입니다. 휴대폰에서 선택하는 통화 녹음 폴더와는 별개입니다.

서비스시작을 누르세요.

서버 연결 완료 상태를 확인합니다. 휴대폰과 다른 상담원이 사용하는 동안 이 PC와 프로그램을 실행해 두세요.

휴대폰에는 이 PC와 같은 원격주소·비밀번호·사용자정보를 입력합니다. 화면의 ‘123 abc’는 설명용 예시입니다.

03

휴대폰 홈에서 연결 정보를 저장하세요.

화면의 접힌 항목을 누르면 입력란이 열립니다.

원격주소 (필수입력)를 펼치세요.

호스트 PC에 표시된 원격주소와 설정한 비밀번호를 입력하고 저장을 누릅니다.

사용자 정보 (필수입력)를 펼치세요.

이름 또는 닉네임에 PC의 사용자정보와 같은 이름을 입력한 뒤 저장하세요.

녹음 폴더 선택을 누르세요.

휴대폰의 실제 통화 녹음 폴더를 선택합니다. 일부 삼성 휴대폰은 Recordings/Call을 사용하지만 기기에 따라 다릅니다.

요청된 권한을 확인하고 서비스를 시작하세요.

앱에서 요청하는 전화·알림·파일 접근 권한을 확인합니다. 홈으로 돌아와 서비스 시작을 누르세요.

이미 서비스가 실행 중이면 서비스 중지를 누른 뒤 연결 정보를 수정·저장하고 다시 시작하세요. 녹음 기능은 휴대폰 전화 앱의 통화 녹음 설정이 필요하며, 폴더를 선택하는 것만으로 녹음이 시작되지는 않습니다.

04

PC에서 승인하고 첫 통화를 확인하세요.

중계기 연결 표시만으로 휴대폰의 접속 승인이 끝난 것은 아닙니다.

01

호스트 PC에서 승인

최초 접속 요청에 표시된 사용자정보와 기기를 확인하고 승인합니다.

02

연결 상태 확인

휴대폰의 서비스 상태가 실행 중인지, 호스트 PC에 승인된 접속자가 표시되는지 확인합니다.

03

통화 알림 열기

연결한 휴대폰으로 테스트 전화를 걸거나 받아 보세요. PC 우측 하단 알림을 열어 이력을 확인하고 메모를 남깁니다.

다른 상담원 PC도 연결하려면
  • 추가 PC에서 홈 → 클라이언트 탭을 엽니다.
  • 호스트의 원격주소·비밀번호와 해당 상담원의 사용자정보를 입력합니다.
  • 서버 연결을 누르고, 호스트 PC에서 새 기기의 접속을 승인합니다.
  • 이력을 제공하는 호스트 PC를 계속 실행해 두세요.
?

연결이 잘 안 되나요?

휴대폰이 서버에 연결되지 않아요.

호스트 PC의 서비스가 실행 중인지, 원격주소와 비밀번호가 맞는지, PC에서 최초 접속을 승인했는지 확인하세요.

전화는 오는데 PC 알림이 안 보여요.

PC와 휴대폰의 사용자정보가 같은지 확인하세요. 모바일 서비스가 실행 중인지, 앱이 요청한 전화·알림 권한이 허용되어 있는지도 확인합니다.

녹음이나 텍스트 기록이 없어요.

휴대폰에 실제 녹음 파일이 저장되는지, 선택한 폴더가 맞는지 확인하세요. ‘Wi-Fi 시에만 업로드’가 켜져 있으면 Wi-Fi 연결도 확인해 주세요.

잔여 시간이 없다고 표시돼요.

PC 앱에서 충전을 눌러 인증된 페이지에서 이용권을 선택하세요. 결제가 끝나면 잔여 시간의 갱신 버튼을 누릅니다.

추가 문의는 PC 앱의 공지사항 메뉴에서 확인하고 문의를 남길 수 있습니다.

연결됐다면, 다음 상담을 이어가세요.

통화 알림과 이력, 메모, AI 채팅을 화면으로 둘러보세요.
